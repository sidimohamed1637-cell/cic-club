# 🚀 البوابة الرقمية لنادي الإبداع والابتكار (STI - ST CLUB)
### كلية العلوم والتكنولوجيا - جامعة تامنغست

تطبيق ويب حديث ومتكامل، مصمم بهوية إلكترونية تقنية داكنة باللون الأزرق المضيء (Dark Circuit Tech Theme) مستوحى مباشرة من شعار نادي الإبداع والابتكار (STI).

---

## 🌟 مميزات التطبيق

1. **واجهة باللغة العربية بالكامل وبدعم كامل لـ RTL (`dir="rtl"`)**:
   - خطوط عربية تقنية أنيقة (`Cairo`).
   - استجابة تامة (Responsive) لجميع شاشات الهواتف الذكية والأجهزة اللوحية والحواسيب.

2. **الواجهة العامة (Public Portal)**:
   - **هيدر مثبت (Navbar)**: بشعار النادي وقائمة جانبية متجاوبة للهواتف وزر انضمام سريع (دون أي رابط للأدمن للحفاظ على الخصوصية).
   - **قسم التعريف بالنادي (عن النادي)**: رؤية، رسالة، وأهداف النادي الاستراتيجية.
   - **المحاور والخدمات التقنية**: بطاقات تفاعلية لمسارات الروبوتات، برمجة الأنظمة المدمجة (Arduino / ESP32)، تصميم الدوائر (PCB)، الذكاء الاصطناعي، والهاكاثونات.
   - **البطاقة التقنية والوثائق الرسمية**: إمكانية تحميل البطاقة التقنية بضغطة زر ومعاينة رمز الاستجابة السريعة (QR Code).
   - **المكتب التنفيذي والأستاذ المشرف**: بطاقات مخصصة بإطارات دائرية مضيئة بالأزرق السماوي للأستاذ المشرف وأعضاء المكتب التنفيذي.
   - **الدورات والورشات التدريبية**: عرض الدورات المتاحة مع زر "تسجيل في الدورة" يفتح نافذة منبثقة لتسجيل بيانات الطالب وحضورهم.
   - **نموذج الانضمام الشامل للعضوية**: رفع الشهادة المدرسية وبطاقة الطالب إلى **Firebase Storage** وحفظ بيانات العضوية في **Firestore**.
   - **قسم التواصل والفوتر**: عرض البريد الإلكتروني الرسمي للنادي وروابط السوشيال ميديا المباشرة (فيسبوك، انستغرام، واتساب، ديسكورد/لينكد إن).

3. **لوحة تحكم الأدمن السرية والمخفية (Secret Admin Dashboard)**:
   - لا تظهر في القائمة العامة أو الفوتر إطلاقاً.
   - المسار السري للوصول: `/#/admin` (أو `/admin`).
   - شاشة تسجيل دخول للأدمن عبر **Firebase Authentication**.
   - **جدول الأعضاء المتقدمين**: معاينة وتحميل الشهادة المدرسية وبطاقة الطالب لكل طالب، وتصدير القوائم إلى Excel / CSV.
   - **إدارة الدورات التدريبية**: إضافة دورات جديدة وحذفها فورياً لتظهر لزوار الموقع.
   - **قوائم تسجيل الورشات**: فرز الطلبة المسجلين حسب كل ورشة مع إمكانية التواصل الفوري عبر واتساب وتصدير الحضور.

4. **نظام التبديل السلس الذكي (Dual-Engine: Firebase & Local Fallback)**:
   - يعمل التطبيق محلياً فوراً وبكفاءة 100% حتى قبل إدخال مفاتيح Firebase (عبر محرك تخزين تجريبي متقدم).
   - بمجرد وضع مفاتيح Firebase في ملف `.env.local`، يتحول التطبيق تلقائياً للعمل مع Firebase السحابي دون تعديل أي كود.

## 🛠️ التشغيل والتجربة محلياً (Local Development)

### 1. تثبيت الحزم (إذا لزم الأمر):
```bash
npm install
```

### 2. تشغيل السيرفر المحلي:
```bash
npm run dev
```
سيفتح الموقع على الرابط: `http://localhost:3000`

### 3. الدخول إلى لوحة تحكم الأدمن السرية:
افتح الرابط:
```
http://localhost:3000/#/admin
```
بيانات الدخول الافتراضية للتجربة (Demo Mode):
- **البريد الإلكتروني:** `admin@sticlub.dz`
- **كلمة المرور:** `admin123456`
(أو انقر على زر **"تعبئة بيانات التجربة السريعة"** في شاشة تسجيل الدخول).

## ☁️ ربط Firebase (Firestore, Storage, Authentication)

1. توجه إلى [Firebase Console](https://console.firebase.google.com) وأنشئ مشروعاً جديداً.
2. فعّل الخدمات التالية:
   - **Authentication**: اختر طريقة تسجيل الدخول (Email/Password) وأنشئ حساب الأدمن.
   - **Cloud Firestore**: أنشئ قاعدة بيانات بوضع الاختبار.
   - **Firebase Storage**: أنشئ مستودع تخزين للملفات.
3. أنشئ ملفاً باسم `.env.local` في المجلد الرئيسي وضع به مفاتيح مشروعك:
```env
VITE_FIREBASE_API_KEY=مفتاح_API_الخاص_بك
VITE_FIREBASE_AUTH_DOMAIN=اسم_مشروعك.firebaseapp.com
VITE_FIREBASE_PROJECT_ID=اسم_مشروعك
VITE_FIREBASE_STORAGE_BUCKET=اسم_مشروعك.appspot.com
VITE_FIREBASE_MESSAGING_SENDER_ID=رقم_المرسل
VITE_FIREBASE_APP_ID=معرف_التطبيق
```

## 🌐 الرفع على GitHub Pages

المشروع جاهز ومعد للنشر على GitHub Pages:
1. في ملف `package.json` يمكنك إضافة سكريبت النشر `gh-pages` أو استخدام GitHub Actions التلقائي.
2. قم ببناء المشروع:
```bash
npm run build
```
ينتج مجلد `dist` جاهز للرفع على أي استضافة ثابتة أو عبر فرع `gh-pages`.
بفضل اعتماد `HashRouter` والمسار النسبي `./` في `vite.config.js`، لن تواجه أي مشكلة في مسارات الروابط أو شاشات 404 عند تحديث الصفحة على GitHub Pages.

- بيانات ومحاور الدورات التدريبية الافتراضية.
